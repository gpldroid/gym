# FitLife — الصحة واللياقة

تطبيق ويب تقدمي (PWA) عربي/إنجليزي للصحة واللياقة، يعمل على الهاتف والكمبيوتر ويمكن تثبيته كتطبيق.

## المزايا
- لوحة تحكم يومية للصحة واللياقة
- حاسبة BMI
- تقدير السعرات اليومية (TDEE)
- خطة تمارين أسبوعية
- متتبع الماء
- سجل التقدم باستخدام localStorage
- وضع داكن/فاتح
- العربية والإنجليزية
- PWA قابلة للتثبيت والعمل دون اتصال
- تصميم Responsive

> المحتوى لأغراض تعليمية عامة ولا يُعد تشخيصًا أو نصيحة طبية.
